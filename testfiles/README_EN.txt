TEST FILES (self-made, no third-party content)

The same content in every format: 12 pages, coloured areas with a big page number,
pages 5 and 6 in landscape. After a conversion the pages 1 to 12 must come out in this order.

Input files (to convert):
  Testcomic_CBR.cbr    is technically a ZIP with the extension .cbr (not a real RAR, no RAR
                       program was available to create one). For a test with a real RAR on
                       Windows, create your own .cbr with WinRAR.
  Testcomic_EPUB.epub  built by hand, 12 pages in reading order
  Testcomic_PDF.pdf    12 pages, 150 ppi
  Testcomic_MOBI.mobi  Mobipocket (older format)
  Testcomic_AZW.azw    like MOBI, different extension
  Testcomic_AZW3.azw3  KF8 (newer Kindle format)
  Testcomic_CB7.cb7    comic archive as a 7-Zip file
  Testcomic_CBT.cbt    comic archive as a TAR file (with timestamp 1970, as is common in practice)
  Testcomic_KEPUB.kepub.epub   Kobo EPUB variant (here a normal EPUB with this extension)

For comparison:
  Testcomic_Original_CBZ.cbz   this is what the result should look like
  Ergebnis_aus_AZW3.cbz / Ergebnis_aus_AZW.cbz   already converted (Mac app)

NOTE: CBZ files with the same name are skipped. All input files have different names, but
after converting, move the result (e.g. Testcomic_PDF.cbz) away before you test the same file again.
